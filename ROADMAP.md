# Дорожная карта

Источник требований — `REQUIREMENTS-2.0.md` (локальная копия у сопровождающего). Тег `v2.0.0` означает **Server**. Профиль Desktop ведётся в ветках `desktop-3.x` и в эту карту как работа `main` не входит. Общие куски (память, SMP, VFS, сеть, динамический линкер) делаются на `main`, потому что без них не соберётся и сервер.

Критический путь: **SMP → VFS, page cache, ext4 → динамический линкер и сигналы → сеть → init и пакеты → самосборка**.

| Версия | Содержание | Статус |
|---|---|---|
| 1.0.0, 1.0.1 | ext2-корень, проверка указателей, возврат кадров | теги стоят, не двигаются |
| 1.1 | SMP, APIC/x2APIC, IPI, per-CPU, часы не на 18 Гц, настоящее время суток, настоящий futex и rseq | начато: TSC; таймер BSP LAPIC ~250 Гц; AP паркуются и отвечают на IPI; RTC в `CLOCK_REALTIME`; `futex WAIT/WAKE`; `rseq` на вытеснении из ring 3. Нет очереди задач на AP, x2APIC, per-CPU TSS, `FUTEX_REQUEUE`/PI |
| 1.2 | IPv4/IPv6, virtio-net, сокеты, netlink | начато: legacy virtio-net, DHCP и ARP на 8 соседей, UDP `AF_INET` с суммой (0 на IPv4 принимается) и петля `127.0.0.0/8`. Нет IPv6, TCP, netlink |
| 1.3 | `PT_INTERP`, сигналы, epoll, `/proc`, `/sys` | начато: `/proc` (`uptime`, `cpuinfo`, `meminfo`, `stat`) и короткий `/sys`; перехваченный сигнал с `SA_RESTORER` доставляется на возврате из syscall и с тика в ring 3; epoll level-triggered по номеру fd; `PT_INTERP` грузит один ELF интерпретатора и входит в него (`AT_ENTRY`/`AT_PHDR` — основная программа). Нет доставки смертельного сигнала с тика, edge-trigger, поиска символов |
| 1.4 | блочный слой, NVMe/AHCI, page cache, ext4 | нет |
| 1.5 | PID1, пользователи, пакеты | нет |
| 1.6 | только то из USB и консоли, без чего сервер в облаке не живёт. DRM/KMS и Wayland сюда не входят — это `desktop-3.x` | нет |
| 1.7 | namespaces, cgroups v2, seccomp, capabilities, контейнеры | нет |
| 1.9 | HCL серверов и гипервизоров, фаззинг, бенчмарки, внешний аудит, RC | нет |
| 2.0.0 | стабилизация Server, документация, LTS 3 года | нет |
| 3.x | Desktop: Wayland, GPU, звук, Wi-Fi, suspend, установщик с GUI | ветка не открыта |

Пункты 0.1–0.9 записаны в `doc/`: [compat-contract](doc/compat-contract.md), [profiles](doc/profiles.md), [architecture](doc/architecture.md), [unsafe](doc/unsafe.md), [governance](doc/governance.md). aarch64 (0.10) и HCL (0.11) в 2.0.0 не обязательны и не начаты.

Долг 1.1: задачи исполняет только BSP. AP подняты и стоят в `hlt`, своего TSS и тика у них нет. Пока `sys_clone` и разбор адресного пространства держат IF выключенным, тик LAPIC на BSP не приходит и квант сдвигается. `nanosleep` и `CLOCK_MONOTONIC` на TSC. `CLOCK_REALTIME` — CMOS RTC, без NTP. `FUTEX_REQUEUE` и PI нет. `rseq` не обрывает критическую секцию на входе в syscall.

Долг 1.2: кэш ARP — восемь записей, девятая вытесняет самую старую. `SO_REUSEADDR` и `SO_BROADCAST` принимаются и не запоминаются. Датаграмма UDP не длиннее 1280 байт. Адрес с карты появляется после DHCP, сам по себе при загрузке не запрашивается. `SOCK_STREAM` возвращает `EPROTONOSUPPORT`. Сумма 0 у входящего UDP на IPv4 не проверяется.

Долг 1.3: перехваченный сигнал с `SA_RESTORER` доставляется, когда тик возвращается в ring 3, и на возврате из syscall. Смертельный сигнал и `SIGKILL` с тика не забираются. Блокирующий `read` и `nanosleep` сигнал не прерывают. Чужой tid получает бит и входит в обработчик на своём тике или syscall. `SIGSTOP` и сигналы остановки сбрасываются. Нет `SA_RESTART`, очереди rt-сигналов (32–64), `SIGCHLD` при `exit`. `PT_INTERP` — один уровень: вложенный интерпретатор отвергается, `ET_DYN` принимает только `R_X86_64_RELATIVE`, поиска символов нет. Интерпретатор `ET_EXEC` садится на свой адрес, `ET_DYN` — на `0x800000`. Смерть по умолчанию — `exit(128+sig)`, не `WIFSIGNALED`. Без `SA_RESTORER` перехваченный сигнал не доставляется: для смертельных по умолчанию это `exit`. epoll следит за номером fd, не за описанием файла: `close` этого номера снимает интерес, даже если остался `dup`. `EPOLLET` принимается и остаётся level-triggered. `epoll_pwait` маску сигнала не ставит. poll и select по самому epoll-fd ничего не видят. Таймаут длиннее 60 с — `EINVAL`. Наборов не больше 16, интересов не больше 32. `/proc/meminfo` — usable из карты и свободные кадры, не MemAvailable. `/proc/stat` кладёт тики планировщика в поле system, user и idle не разделяет. `/sys` — два файла и каталоги до них, не sysfs.
